# 10人村：放置したら人間関係が崩壊した

小さな3Dの村に暮らす10人のNPCを、ただ眺めるだけの放置観察ゲームです。
プレイヤーは基本的に介入せず、性格・欲求・記憶・噂・恋愛・嫉妬といったルールから
自然に生まれる人間関係の変化(仲良し、恋愛、喧嘩、噂、仲間外れ、派閥…)を観察します。

## 遊び方

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開いてください。

- **カメラ**: ドラッグで回転、右ドラッグ/2本指ドラッグで移動、ホイールでズーム
- **NPCクリック**: 詳細パネル(性格・欲求・記憶・全員への好感度)を表示
- **時間速度**: 画面上部の ⏸ / ×1 / ×2 / ×5 / ×10 で切り替え
- **関係マップ**: 村全体の人間関係をノードグラフで可視化(力学的に配置され、時間とともに乱れていきます)
- **デバッグ**: 全NPCの性格・状態・関係値・記憶を一覧表示
- **新しい村を作る**: NPC・性格・初期関係をすべて再生成してリスタート

## ビルド

```bash
npm run build
npm run preview
```

## 技術構成

TypeScript + Three.js + Vite。外部サーバー・API・AIは一切使用せず、
すべてルールベースのロジック(性格・欲求・関係値・記憶・噂の伝播)で
NPCの行動と物語を生成しています。

主なパラメータは `src/config.ts` に集約されており、ゲームバランスの調整はここから行えます。
